# Design fidelity

## Current operational direction — 30 October 2026

The new product brief supersedes the earlier authenticated dark-card design below. `operations.css` scopes a single light workspace to `.app-shell`: charcoal 224px navigation, 64px white header, 24px canvas padding, white surfaces, dark text, 13px or larger tables and restrained orange actions. Red/amber/blue/green states include text. Public welcome branding remains unchanged. Specialised Action desk, queue, case review, Committee agenda, EVC planner, Compliance ledger, Evidence review and visual policy editor replace the generic layouts.

Current before/after evidence and finite accessibility results belong to the dated operational report. Earlier captures below describe historical source only. No formal GIGW/WCAG certification is claimed.

Operational cards use 16px radius, thin white/10 borders, orange hover/focus and 44px interactive buttons; inputs use 48px and translucent black/lower-edge borders. Decision targets do not move. Hero display uses responsive 40–68px; operational headings 25–30px, panels 16–24px. This density adaptation is intentional.

Accessibility: dark #030304 labels on original orange gradient. Muted text retains #94A3B8, rather than white/30. Explicit state text accompanies colors. Radix Dialog provides mobile navigation focus trapping, title and dismissal. Skip link, labelled inputs, semantic tables and visible focus are implemented. Table scrolling stays inside its positioned container; positioning fixed an actual 390px overflow caused by a visually hidden header. `prefers-reduced-motion` disables animations; a persisted harmless preference pauses them. Live updates invalidate query data without replacing unsaved local form text.

Actual Playwright capture sizes: 1440×900; overview also 1280×800, 768×800 and 390×800. Screenshots are generated by the real app and database, not fabricated. Welcome cards are explicitly illustrative and contain no confidential counts. PDF/print uses light report styling. Detailed keyboard/contrast checks are in the executed browser tests and measurement evidence; no blanket WCAG certification is claimed.

Visual inspection caught a blank browser-plugin PDF frame. The review workspace now uses a locally bundled PDF.js worker, canvas rendering, page navigation and accessible extracted text. Font/CMap/WASM support assets are copied locally at build time; no CDN is used. The browser test waits for a rendered canvas and extracted text before taking review evidence.
